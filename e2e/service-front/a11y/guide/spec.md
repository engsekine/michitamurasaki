# guide（E2E 仕様）

## 目的

使い方ページ（/guide）は未ログインの訪問者にも公開する数少ない検索対象ページであり、認証ガードや noindex の適用漏れが起きるとページの存在意義が失われる。公開性（リダイレクトされない・インデックス可）と、6 セクション構成・目次移動・登録導線・モバイル表示・WCAG 2.1 AA 準拠を守る。

## 対象

- アプリ: service-front（http://localhost:9323）
- 画面 / URL: `/guide`、`/signup`（登録導線の遷移先）
- 関連仕様: `specs/030-usage-guide/spec.md`（FR-001 未ログイン閲覧可、FR-002 6 セクション構成、FR-003 目次、FR-005 登録導線、FR-010 インデックス可、SC-004 横スクロールなし）

## 前提

- 認証: 未認証（NO_AUTH）。シナリオ 4 のみテスト内で SERVICE_USER（test@example.com）にログイン
- Cookie 同意: 同意済みプリセット（fixture 既定）
- データ: seed のみ
- その他: シナリオ 5 のみ viewport を 375×812 に変更

## シナリオ

| # | テスト名 | 検証内容 |
|---|---|---|
| 1 | 使い方ページ - 未ログインでリダイレクトされず表示され WCAG 2.1 AA 違反なし | 未ログインで `/guide` を開き URL が `/guide` のまま h1「使い方」が表示されること、h2 が 6 セクション（はじめに / ダイブログを記録する / ダイビング予定と持ち物リスト / ダッシュボードで振り返る / みんなのログ・いいね / ログ枠と追加購入）すべて表示されることを確認し、axe で違反がないことを確認する。 |
| 2 | 使い方ページ - robots メタに noindex が含まれない（FR-010） | `meta[name="robots"]` が 1 件存在し、`content` に `noindex` が含まれないことを確認する。 |
| 3 | 使い方ページ - 登録導線から新規登録画面へ遷移できる（FR-005） | ページ末尾の「無料で始める」リンクをクリックし `/signup` へ遷移することを確認する。 |
| 4 | 使い方ページ - ログイン済みでも同一コンテンツが表示される（FR-001） | SERVICE_USER でログイン後に `/guide` を開き、URL が `/guide` のまま h1「使い方」が表示されることを確認する。 |
| 5 | 使い方ページ - モバイル幅（375px）で横スクロールが発生しない（SC-004） | viewport 375×812 で `/guide` を開き、`document.documentElement` の `scrollWidth <= clientWidth` であることを確認する。 |
| 6 | 使い方ページ - 目次から各セクションへ移動し、目次に戻れる（FR-003） | `navigation`「目次」内の「ダッシュボードで振り返る」リンクで URL が `#dashboard` になり該当 h2 が viewport 内に入ること、「目次に戻る」リンクを focus + Enter で発火して URL が `#guide-toc` になり目次が viewport 内に戻ることを確認する。 |

## 備考

- シナリオ 1・5 は axe 実行 / 幅計測の前に `networkidle` を待っている。
- シナリオ 6 の「目次に戻る」はセクションごとに複数あるため `first()` を使う。

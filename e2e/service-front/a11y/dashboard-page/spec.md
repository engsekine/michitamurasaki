# dashboard-page（E2E 仕様）

## 目的

TOP（ダッシュボード）はグラフや累計統計が集まるページで、グラフを視認できないユーザー向けの代替データテーブルが提供されている。代替テーブルを閉じた既定状態と、すべて開いた状態の両方で WCAG 2.1 AA 違反がないことを守る。

## 対象

- アプリ: service-front（http://localhost:9323）
- 画面 / URL: `/`（ログイン済み TOP = ダッシュボード）
- 関連仕様: `specs/003-dashboard/spec.md`（累計ダイビング本数）、`specs/010-stats-expansion/spec.md`（FR-009 グラフの代替表現）

## 前提

- 認証: ログイン済み（setup project の storageState）
- Cookie 同意: 同意済みプリセット（fixture 既定）
- データ: seed のみ
- その他: なし

## シナリオ

| # | テスト名 | 検証内容 |
|---|---|---|
| 1 | TOP（ダッシュボード）- 累計ダイビング本数を含めて WCAG 2.1 AA 違反なし（要認証） | `/` を開き見出し「累計ダイビング本数」の表示後に axe を実行。続けてページ内の「データを表で見る」（details の summary）をすべてクリックして代替データテーブルを展開した状態でも違反がないことを確認する。 |

## 備考

- 「データを表で見る」はグラフの数だけ存在するため、`count()` で件数を取ってすべて開いている（件数はデータに依存するので固定値にしていない）。

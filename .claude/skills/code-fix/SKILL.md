コード規約に基づいて現在のブランチのコードを修正します。

## 使い方

- `/code-fix` — 変更ファイル全体を対象に修正
- `/code-fix $ARGUMENTS` — 指定したファイルのみ修正（例: `src/components/Button.tsx`）

## 手順

### 1. 対象ファイルの特定

引数 `$ARGUMENTS` が指定されている場合:
- 指定ファイルのみを対象とする
- ファイルが存在しない場合は「指定ファイルが見つかりません: $ARGUMENTS」と出力して終了

引数がない場合は [.claude/rules/diff-scope.md](../../rules/diff-scope.md) に従い、未ステージ・ステージング済み・コミット済みの 3 層を統合した変更ファイル一覧を取得する（コミット済みの変更も修正対象に含める）。差分がなければ「修正対象のファイルがありません」と出力して終了。

### 2. コード規約の読み込み

対象ファイルの拡張子に応じて、該当する規約ファイルを読み込む:

| 拡張子 | 読み込む規約 |
|--------|------------|
| `.ts`, `.tsx` | `.claude/rules/typescript.md`, `.claude/rules/react.md` |
| `.css` | `.claude/rules/css.md` |
| `.html` | `.claude/rules/html.md` |
| `.php` | `.claude/rules/php.md` |
| `.sql` | `.claude/rules/sql.md` |

全ファイル共通で以下も読み込む:
- `.claude/CLAUDE.md` — プロジェクト共通規約
- `.claude/rules/accessibility.md` — アクセシビリティ規約（`.tsx`, `.html` の場合）
- `.claude/rules/readable-code.md` — 命名規則（全拡張子）

規約ファイルが一つも存在しない場合は「コード規約ファイルが見つかりません。`.claude/rules/` に規約を追加してください」と出力して終了。

**規約間の競合時**: `.claude/CLAUDE.md` > `.claude/rules/` 配下の個別規約。プロジェクト共通規約が最優先。

### 3. レビュー結果の参照

同一セッション内で直近に `/review` を実行した結果がある場合は、その Error・Warning 指摘を修正対象リストに追加する。`/review` を実行していない場合はこのステップをスキップする。

### 4. ファイルごとの修正

対象ファイルを1つずつ確認し、規約に違反している箇所を修正する。

**判定基準と修正ポリシー:**

| レベル | 判定基準 | 修正方法 |
|--------|---------|---------|
| **Error** | 型エラー、`any` の使用、未使用 import、セキュリティ脆弱性 | Edit ツールで自動修正する |
| **Warning** | 命名規則違反、宣言的スタイル違反（手続きループ→配列メソッド等）、早期リターン未使用 | Edit ツールで自動修正する。ただし変数・関数名の変更が他ファイルの import に波及する場合は Info に格下げし手動確認を促す |
| **Info** | コメントの改善提案、より良い命名の提案 | 修正せず、サマリーに「手動確認推奨」として記載 |

### 5. biome check の実行

修正を 1 件以上適用した場合、最後に必ず実行する（CLAUDE.md「レビュー修正ルール」）:

```bash
npx biome check .
```

- 指摘があれば `npx biome check --write .` で修正する
- `--write` で解消しないエラーは手動で修正する
- biome check が通らない状態で完了報告しない

### 6. 修正内容のサマリー表示

```
コード修正完了
═══════════════════════════
対象: <ファイル数>ファイル
適用規約: <読み込んだ規約ファイル一覧>

修正内容:
- [ファイルパス:行番号] [修正内容]
...

手動確認が必要な箇所: <件数>件
- [ファイルパス:行番号] [Info内容]

biome check: <パス / --write で N 件修正後にパス>
```

## $ARGUMENTS

指定ファイルパス（省略可）。省略時は変更ファイル全体が対象。

# Feature Specification: ダイバー種別・ダイバー番号の登録

**Feature Branch**: `019-diver-type`

**Created**: 2026-06-29

**Status**: Draft

**Input**: User description: "ユーザー登録の際ににインストラクターか普通のダイバーかの項目を追加する / 任意でダイバー番号も記載できるように"

## Clarifications

### Session 2026-06-29

- Q: ダイバー種別の選択肢と必須要否は? → A: 「インストラクター / 一般ダイバー」の **2 択で必須**（未選択は許容しない）
- Q: 任意の「ダイバー番号」の扱いは? → A: **インストラクターを選んだ場合のみ**入力可（その場合も任意）。一般ダイバーでは番号欄を出さず保存しない
- Q: 既存ユーザーの編集時にダイバー種別を必須にするか? → A: **新規登録時のみ必須**。プロフィール編集（`/settings/profile`）では任意（未選択のまま保存可）とし、既存ユーザーをブロックしない
- Q: ダイバー番号のバリデーション（長さ・文字種）は? → A: **50 文字以内・文字種制限なし**（前後空白はトリム、空白のみ・空欄は番号なし=null として扱う）。認定団体固有の形式チェックはしない

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 登録時にダイバー種別を選ぶ (Priority: P1)

新規ユーザーとして、アカウント登録時に「インストラクター」か「一般ダイバー」かを選び、自分の立場をプロフィールに反映したい。

**Why this priority**: ダイバー種別はプロフィールの基本属性で、将来的な表示・機能分岐（例: インストラクター向け機能）の土台になる。本要望の中心。

**Independent Test**: `/signup` でダイバー種別を選択して登録し、登録後のプロフィールにその種別が保存・表示されることを確認すれば単独で検証できる。

**Acceptance Scenarios**:

1. **Given** 新規ユーザーが `/signup` を開いている、**When** ダイバー種別（インストラクター / 一般ダイバー）を選んで登録する、**Then** システムは選択した種別をプロフィールに保存する
2. **Given** 未登録の Google アカウントで初回ログインしたユーザーが `/profile-completion` を開いている、**When** ダイバー種別を選んで送信する、**Then** システムは選択した種別を保存する
3. **Given** 登録済みユーザーがプロフィール編集（`/settings/profile`）を開いている、**When** ダイバー種別を変更して保存する、**Then** システムは新しい種別を反映する

---

### User Story 2 - インストラクターは任意でダイバー番号を登録する (Priority: P2)

インストラクターとして、自分のダイバー番号（認定番号など）を任意で登録しておきたい。未入力でも登録できることを期待する。一般ダイバーには番号欄は表示されない。

**Why this priority**: 種別（US1）が成立した後の付加情報。任意項目かつインストラクター限定のため、優先度は P2。

**Independent Test**: 種別でインストラクターを選ぶとダイバー番号欄が現れ、入力して登録 → 保存／空で登録 → 完了の両方を確認。一般ダイバーでは番号欄が出ないことを確認すれば単独で検証できる。

**Acceptance Scenarios**:

1. **Given** 種別で「インストラクター」を選んでいる、**When** ダイバー番号を入力して登録する、**Then** システムはダイバー番号を保存する
2. **Given** 種別で「インストラクター」を選んでいる、**When** ダイバー番号を空のまま登録する、**Then** システムは登録を完了し、ダイバー番号は未登録として扱う
3. **Given** 種別で「一般ダイバー」を選んでいる、**When** フォームを見る、**Then** システムはダイバー番号欄を表示せず、登録時もダイバー番号を保存しない
4. **Given** インストラクターでダイバー番号に許容長を超える / 許容外の文字を入力した、**When** 登録する、**Then** システムはエラーを表示し登録を拒否する

---

### Edge Cases

- ダイバー番号が空（インストラクター）→ 任意項目のため許容し、未登録として保存する
- 一般ダイバーを選択 → ダイバー番号欄は表示されず、保存もされない
- インストラクター → 一般ダイバーへ選択を変えた → 入力済みのダイバー番号は破棄され保存されない（種別と整合）
- 既存ユーザー（本機能以前に登録）→ ダイバー種別・番号は未設定（NULL）のままで、プロフィール編集から後から設定できる
- ダイバー番号が長すぎる / 許容外の文字 → エラー表示して拒否する

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは新規登録フォーム（`/signup`）にダイバー種別の選択（インストラクター / 一般ダイバー）を表示しなければならない
- **FR-002**: システムは Google 初回ログインのプロフィール補完（`/profile-completion`）にも同じダイバー種別の選択を表示しなければならない
- **FR-003**: システムは選択されたダイバー種別をユーザーのプロフィールに保存しなければならない
- **FR-004**: システムはダイバー種別を「インストラクター / 一般ダイバー」の **2 択・必須**として受け付け、未選択での登録を拒否しなければならない
- **FR-005**: システムはダイバー種別で「インストラクター」が選ばれた場合のみ、任意項目「ダイバー番号」を表示・受け付けなければならない。「一般ダイバー」ではダイバー番号欄を表示せず、保存もしてはならない
- **FR-006**: システムはインストラクターのダイバー番号が未入力でも登録を完了できなければならない（任意）
- **FR-007**: システムは入力されたダイバー番号をプロフィールに保存しなければならない
- **FR-008**: システムはダイバー番号を自由記述・**50 文字以内**（前後空白はトリム、空白のみ・空欄は番号なし=null として扱う、文字種制限なし）として受け付け、50 文字を超える場合はエラーを表示し登録を拒否しなければならない（特定の認定団体固有の形式チェックは行わない）
- **FR-009**: システムは登録済みユーザーがプロフィール編集（`/settings/profile`）からダイバー種別・ダイバー番号を変更できるようにしなければならない。種別を「一般ダイバー」に変更した場合はダイバー番号を保持してはならない。**プロフィール編集ではダイバー種別の選択を必須にしてはならない**（未選択のまま保存でき、既存ユーザーをブロックしない。必須は新規登録時のみ）
- **FR-010**: システムは本機能以前に登録した既存ユーザーについて、ダイバー種別・番号を未設定（NULL）として扱い、強制再入力を求めず、後からプロフィール編集で設定できるようにしなければならない

### Key Entities *(include if feature involves data)*

- **ダイバー種別（diver_type）**: ユーザープロフィールの属性。「インストラクター / 一般ダイバー」の 2 値（新規登録では必須）。既存ユーザーは未設定（NULL）を取りうる。`user_details` に保持
- **ダイバー番号（diver_number）**: ユーザープロフィールの任意属性。自由記述・**50 文字以内**（文字種制限なし）。**インストラクターの場合のみ**値を持ち、一般ダイバー・未設定では NULL。`user_details` に保持

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 新規ユーザーが登録フロー（メール / Google 初回）でダイバー種別を選び、登録後のプロフィールに反映されることを追加サポートなしに完了できる
- **SC-002**: ダイバー番号は任意であり、未入力でも 100% 登録を完了できる
- **SC-003**: 登録・プロフィール編集の全受け入れ条件（種別の選択・保存、番号の入力・空許容・バリデーション）が自動テストで再現・合格する
- **SC-004**: ダイバー種別・番号の入力 UI が WCAG 2.1 AA を満たす（ラベル関連付け、キーボード操作、エラーの支援技術への伝達）

## Assumptions

- ダイバー種別・ダイバー番号はユーザープロフィール（`user_details` 相当）の属性として、姓名・生年月日・性別などと同じ仕組みで保存する
- 登録時の入力 UI（プロフィール項目）は `/signup`・`/profile-completion`・`/settings/profile` で共有されるため、本機能の項目も 3 画面に一貫して現れる
- ダイバー番号は自由記述・50 文字以内の任意項目とし、特定の認定団体（PADI / NAUI 等）固有の検証は行わない。インストラクター選択時のみ入力可
- 「ダイバー番号はインストラクターのみ」という制約は、データ整合（一般ダイバーで番号が残らない）も含めて担保する
- 既存ユーザーは本機能以前の登録のため未設定（grandfather）とし、強制的な再入力は求めない
- ダイバー種別による機能・表示の分岐（インストラクター専用機能など）は本フェーズの対象外（属性の登録・表示までを範囲とする）

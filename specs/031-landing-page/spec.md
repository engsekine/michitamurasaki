# Feature Specification: ランディングページ（LP）

**Feature Branch**: `031-landing-page`

**Created**: 2026-07-08

**Status**: Draft

**Input**: User description: "LPを作成したい"

## Clarifications

### Session 2026-07-08

- Q: LP はどこに配置しますか？ → A: 別 URL（`/lp` など専用 URL）に配置する。トップ URL の既存挙動（未認証→ログイン、認証済み→ダッシュボード）は変更しない
- Q: LP のセクション構成はどの範囲まで含めますか？ → A: 標準構成（ヒーロー・機能紹介・料金・CTA・フッター）に加えて実際の画面イメージ（スクリーンショット）を機能紹介に添える。「利用の流れ」「FAQ」はスコープ外
- Q: 料金セクションに具体的な価格を明示しますか？ → A: 明示する（現行価格をそのまま掲載）。注: 当初「10 枚 500 円」（product.md の構想値）としたが、実装上の現行価格は**ログパック 10 枠 300 円**のため実装に合わせて訂正（2026-07-08 /speckit-plan 時）。その後 2026-07-16 の価格改定で 3 パック構成（お試し 10 枠 480 円 / おすすめ 30 枠 1,200 円 / たっぷり 100 枠 3,000 円）へ変更

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 未認証の訪問者がサービスを理解して新規登録に進む (Priority: P1)

ダイビングログサービスを知らない訪問者（検索・SNS・口コミ経由）が LP の専用 URL にアクセスすると、認証なしでランディングページが表示される。訪問者はキャッチコピーとサービス紹介（ログ記録・統計ダッシュボード・ダイビング予定・仲間とのタイムライン共有など）を読み、「このサービスで何ができるか」を理解したうえで、ページ内の登録導線から新規登録へ進める。

**Why this priority**: 現状、未認証の訪問者はサービスの価値を知る手段がなくログイン画面に誘導されるだけで、新規ユーザー獲得の入口が存在しない。LP の第一の目的はこの獲得導線の確立であり、これが無ければ本機能の価値はない。

**Independent Test**: 未ログイン状態で LP の URL にアクセスし、サービス紹介コンテンツが表示されること・登録導線をたどって新規登録画面に到達できることを確認すれば、単体で価値検証が完了する。

**Acceptance Scenarios**:

1. **Given** 未ログイン状態、**When** LP の専用 URL にアクセスする、**Then** ランディングページが表示される（ログイン画面へリダイレクトされない）
2. **Given** ランディングページを表示中、**When** 主要な登録ボタン（ファーストビュー内）を押す、**Then** 新規登録画面に遷移する
3. **Given** ランディングページを表示中、**When** ページを最後までスクロールする、**Then** サービスの主要機能の紹介と料金の説明を経て、最下部にも登録導線がある
4. **Given** ランディングページを表示中、**When** ログイン導線を押す、**Then** ログイン画面に遷移する（既存ユーザーの迂回路）

---

### User Story 2 - 既存の画面遷移に影響を与えない (Priority: P2)

LP は独立した専用 URL として追加され、トップ URL やログイン後の画面遷移など既存の挙動には一切影響しない。ログイン済みのユーザーが LP の URL を開いた場合も閲覧でき（リダイレクトされない）、LP 内の導線からアプリに戻れる。

**Why this priority**: LP は新規獲得のための追加であり、既存ユーザーの体験を後退させてはならない。P1 と同時に成立して初めてリリース可能になる退行防止の要件。

**Independent Test**: LP 追加後に、未認証でトップ URL にアクセスするとログイン画面へ、ログイン済みでトップ URL にアクセスするとダッシュボードへ、それぞれ従来どおり遷移することを確認する。

**Acceptance Scenarios**:

1. **Given** LP 追加後、**When** 未ログイン状態でトップ URL にアクセスする、**Then** 従来どおりログイン画面へ誘導される
2. **Given** LP 追加後、**When** ログイン済み状態でトップ URL にアクセスする、**Then** 従来どおりダッシュボードが表示される
3. **Given** ログイン済み状態、**When** LP の専用 URL にアクセスする、**Then** LP がそのまま閲覧できる（強制リダイレクトされない）

---

### User Story 3 - 検索・SNS 経由の流入で正しく内容が伝わる (Priority: P3)

検索結果や SNS でシェアされたリンクからの流入時に、サービス名・説明文・シェア用画像が適切に表示され、訪問者がリンクを踏む前からサービス概要を把握できる。また、スマートフォンからの閲覧でもレイアウトが崩れず快適に読める。

**Why this priority**: LP の主要な流入経路は検索と SNS であり、そこでの見え方が流入数を左右する。ただしページ本体（P1）が存在しなければ意味がないため P3。

**Independent Test**: ページのタイトル・説明文・シェア画像のメタ情報が設定されていることと、モバイル幅での表示崩れがないことを確認する。

**Acceptance Scenarios**:

1. **Given** LP が公開されている、**When** SNS で LP の URL をシェアする、**Then** サービス名・紹介文・シェア用画像がプレビューに表示される
2. **Given** スマートフォンで閲覧する、**When** LP を開いてスクロールする、**Then** 全セクションが横スクロールなしで読め、ボタンは指で押しやすい大きさである

---

### Edge Cases

- ログインセッションの有無・期限切れにかかわらず、LP の URL は誰でも閲覧できる（認証チェックの対象外）
- LP 内の統計的な訴求（掲載する場合）は実データに依存させず、静的な文言として管理する（データ取得失敗で LP が壊れないこと）
- 画像が読み込めない環境（低速回線・画像ブロック）でも、テキストだけでサービス内容と登録導線が伝わること
- JavaScript が無効な環境でも、主要コンテンツの閲覧と登録・ログイン画面への遷移ができること

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: LP は専用 URL（例: `/lp`）で公開され、認証の有無にかかわらず誰でも閲覧できなければならない
- **FR-002**: LP の追加によってトップ URL および既存ページの挙動（未認証→ログイン誘導、認証済み→ダッシュボード表示）を変更してはならない
- **FR-003**: LP はファーストビューに、サービスのキャッチコピー・簡潔な説明・新規登録への主要導線を含まなければならない
- **FR-004**: LP はサービスの主要機能（ダイビングログの記録、統計ダッシュボード、ダイビング予定の管理、仲間とのタイムライン共有）を紹介するセクションを含まなければならない
- **FR-004a**: 機能紹介セクションには、実際のサービス画面のイメージ（スクリーンショット等）を添えて訪問者が利用イメージを持てるようにしなければならない
- **FR-005**: LP は料金に関する説明を具体額つきで含まなければならない（基本無料で利用開始でき、ログ枠は 3 種のログパック（お試し 10 枠 480 円 / おすすめ 30 枠 1,200 円 / たっぷり 100 枠 3,000 円）で追加購入できること）。表示する価格・数量はサービス内の販売定義と常に一致していなければならない
- **FR-006**: LP はページ最下部にも新規登録への導線を配置しなければならない（スクロール後の離脱防止）
- **FR-007**: LP には既存ユーザー向けのログイン導線を常時表示しなければならない
- **FR-008**: LP のフッターには利用規約・プライバシーポリシー・お問い合わせへのリンクを含まなければならない
- **FR-009**: LP には検索エンジン・SNS シェア向けのメタ情報（タイトル・説明文・シェア用画像）を設定しなければならない
- **FR-010**: LP はモバイルファーストでレスポンシブに表示され、タッチ操作の対象は十分な大きさ（44×44px 以上）を確保しなければならない
- **FR-011**: LP はアクセシビリティ基準（WCAG 2.1 AA）を満たさなければならない（見出し階層・コントラスト・キーボード操作・代替テキスト）

### Key Entities

本機能は静的な紹介コンテンツのみで構成され、新規のデータ保存・データモデルの変更は行わない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 未ログインの訪問者が、LP アクセスから 5 秒以内にサービスの概要（何ができるサービスか）を把握できる（ファーストビューのみで判断可能）
- **SC-002**: 訪問者がどのスクロール位置からでも 1 操作以内で新規登録またはログインの導線に到達できる
- **SC-003**: LP 経由の新規登録フローが、LP 到達から登録画面表示まで 1 クリックで完了する
- **SC-004**: モバイル・デスクトップ双方で表示崩れ・横スクロールが発生しない
- **SC-005**: トップ URL を含む既存ページの遷移・表示に変化・退行がない
- **SC-006**: アクセシビリティ自動チェックで重大違反 0 件

## Assumptions

- LP は専用 URL に配置する（具体的なパスは実装計画で確定。例: `/lp`）。ログイン済みユーザーが LP を開いた場合もリダイレクトせずそのまま表示する
- LP のコンテンツ（コピー・画像・セクション構成）は静的に管理し、管理画面からの編集（CMS 機能)は本機能のスコープ外とする
- 掲載する文言・画像素材は既存のサービス内表現（サイト名・キャッチコピー「あなたのダイビングのすべてを 1 冊に」・ヒーロー画像等）を流用してよい
- 料金説明は現行のログ枠課金（基本無料 + ログパック 3 種: お試し 10 枠 480 円 / おすすめ 30 枠 1,200 円 / たっぷり 100 枠 3,000 円）の具体額を掲載する。価格・数量はサービス内の販売定義を唯一の情報源として参照し、価格改定時に LP が自動追随する
- 利用規約・プライバシーポリシー・お問い合わせ・新規登録・ログインの各ページは既存のものを利用する（本機能では新設しない）
- 「利用の流れ」「FAQ」「利用者の声」等の追加セクションはスコープ外とする（反応を見て将来追加を検討）
- 画面イメージはスクリーンショット（またはそれを整えたモック画像）を静的素材として用意し、実データの動的取得は行わない
- アクセス解析・A/B テスト・キャンペーン別 LP の出し分けはスコープ外とする（将来検討）
